05 — the shape of the fix

Order the system by how much of it can be proven.

Cryptography and integer arithmetic at the entrance. Accounting invariants at the exit. The learned parts sit in the middle, where the ambiguity actually is — and they may only ever move a decision toward more caution.

      how much friction you are willing to buy

      What these numbers are not.

      • Both corpora are synthetic. Built to be hard — paraphrased duplicates, identical-amount hard negatives, held-out attack families — but not production traffic.
      • The 12% duplicate base rate is a stated assumption. No public figure exists; the sensitivity sweep above is why it is stated rather than hidden.
      • Precision 0.813 means roughly one in five escalations delays a legitimate refund. That cost is real, and it is why the system escalates rather than denies.
      • B1 scoring exactly zero is the corpus working as designed: duplicates are paraphrases, so string equality is worthless and no model is credited for beating a strawman.

      08 — the shared spine

      Every fact cites the events behind it.

      Facts are derived from an append-only log, never asserted. A decision replayed against the same events and the same clock returns the same verdict months later — which is what a chargeback on an agent-initiated order actually requires.

      The obligation is open because no event closes it — not because a model guessed. Replay those events against the same clock in six months and the verdict is identical, which is the only form a dispute can actually use.

      DERIVED_CERTAIN

      UNKNOWN
